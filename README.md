# GeoCloak Web (United States defaults)

Single-page web app that generates bookmarklets to spoof JavaScript geolocation and timezone in Safari/Chrome tabs.

- Start: copy the Run bookmarklet, paste into Safari bookmark URL, and tap it on facebook.com.
- Setup: copy the Setup bookmarklet to save your chosen coordinates on the target domain (run once per domain).
- Stop: reload tab (Stop code provided as a bookmarklet).

Verification: https://browserleaks.com/geo and https://browserleaks.com/time

NOTE: This affects web pages (Safari/Chrome), not the native Facebook app.
