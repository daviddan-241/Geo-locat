GeoCloak — United States defaults

Single‑page helper. Set a location/timezone and generate bookmarklets that make Safari tabs report your chosen location. Works on facebook.com in Safari. Tap Start to generate and copy your Run bookmarklet; tap Stop code to clear overrides (reload).
Usage: 1) Copy Setup and Run to Safari bookmarks on your target domain (e.g., m.facebook.com). 2) Run Setup once to save config on that domain, then Run on each load to apply. 3) Stop = reload tab.
